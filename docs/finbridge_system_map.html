RULE 01
单一存储
QuestDB 是唯一事实源，不引入第二套缓存库；缓存也只是同库读模型或 Parquet 投影。
RULE 02
双写者
raw 表只由 data_interface 写，factor 表只由 factor_engine 写；screener 等一律 0 直连。
RULE 03
单向依赖
factors 不 import 任何业务模块；factor_engine 永不 import acquisition，共享协议下沉到 common。
RULE 04
幂等写入
WAL + DEDUP UPSERT KEYS 覆盖业务键；QuestDB 不支持 DELETE，删除即整分区重建。
RULE 05
时点正确
财务按 publish_date 过滤；板块成分按 as_of 取最近整组快照，避免未来函数与幸存者偏差。
