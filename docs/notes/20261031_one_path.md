# 一条路：固定战场、一个骨架、一个裁判、每周一次

> 现状：框架、数据、因子库都够用了。继续加功能或加因子的边际收益已经是负的。
> 缺的不是工具，是**一个不动的坐标**。下面这套东西只改三个地方，其他全部冻结。

---

## 0. 我们唯一确定的事

同一个因子，换池子结果翻转：

| 池子 | 冠军因子年化 | Sharpe |
|---|---|---|
| 固定 200 池（幸存者偏差） | +8.23% | 0.537 |
| 沪深300（PIT） | -2.48% | -0.10 |
| 中证500（PIT） | +3.59% | 0.30 |

所以「因子有效」不是因子属性，是**因子 × 战场**的属性。
在此之前讨论“下一个因子”，等于在没有标尺的情况下量长度。

---

## 1. 三个固定（先不动）

| 固定项 | 取值 | 理由 |
|---|---|---|
| **战场** | 中证500（`--param index=000905`） | 快照 172 期、2019 起完整；沪深300 上因子失效，中证1000 快照只到 2019-06 |
| **骨架** | `strategies/models/factor_rank.py` | 一条命令换因子，其余（月度、top30、buffer10、等权）全部固定 |
| **裁判** | 2020-01 ~ 2026-10，年化 / Sharpe / 最大回撤 | 只有这三列算数，别的都不算 |

**过线标准（三条全中才留下）**：

1. 单因子 Sharpe ≥ 0.5；
2. 与冠军因子截面 ρ < 0.5；
3. 进合成后，组合 Sharpe 比不加它高 ≥ 0.1。

不过线的因子直接丢，不解释、不换窗口、不调方向。

---

## 2. 每周循环（一次只加一个因子）

- **周一 · 挖 1 个**：只从三个矿里挑（两融 / 资金流 / 结构），一次只挑一个；
- **周三 · 单跑**：`factor_rank.py` 跑单因子，看 Sharpe 过不过线；
- **周五 · 合成**：过线就进 `turnover_regime_margin.py` 的 `parts` 跑组合对比；
  不过线就写一行记录丢掉。

三个矿的候选顺序（已按数据可得性排好）：

| 顺序 | 候选 | 数据 | 状态 |
|---|---|---|---|
| 1 | `sentiment.margin_balance_chg_20d` | margin_detail 2019+ | 已注册，CSI500 单跑 3.87%/0.377 |
| 2 | `sentiment.margin_short_ratio` | 同上 | 已注册 |
| 3 | `sentiment.flow_large_net_ratio_20d` | moneyflow 2022-10+ | 已注册（区间短，需单独看） |
| 4 | 结构类：行业内中性 / regime 条件 | 无新数据 | 未做，等 1-3 跑完 |

## 3. 本周三条命令

```bash
# 1) 战场基线：冠军因子在中证500
python -m backtest run strategies/models/factor_rank.py \
  --start 2020-01-01 --end 2026-10-29 --out console \
  --param index=000905 --param factor=liquidity.turnover_std_bias_42_252 --param direction=-1

# 2) 候选单跑：两融
python -m backtest run strategies/models/factor_rank.py \
  --start 2020-01-01 --end 2026-10-29 --out console \
  --param index=000905 --param factor=sentiment.margin_balance_chg_20d --param direction=-1

# 3) 合成对比（冠军 + 两融）
python -m backtest run strategies/models/turnover_regime_margin.py \
  --start 2020-01-01 --end 2026-10-29 --out console --param index=000905
```

把三组「年化 / Sharpe / 最大回撤」贴回来，就能判定两融在中证500 上是否值得留。

## 5. 冻结清单（这三个月别碰）

- 不再加因子窗口（`84d`、`168d` 之类）；
- 不做全 A（5000 只取数会拖垮迭代速度）；
- 不接分钟线（现有 5m 只有 2 只 × 24 天）；
- 不做参数寻优（`optimize`），先把单因子结论跑出来；
- 不再改回测框架，除非它挡住了上面三条命令。
