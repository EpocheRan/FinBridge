# 因子创意手册：从「没思路」到「有队列」

> 日期：2026-10-31
> 触发问题：`liquidity.turnover_std_bias_42_252` 已是库内最好，下一个因子从哪来。
> 结论：**不是缺灵感，是缺坐标**。库内 146 个因子只用了 2 类数据（价量 + 财务）、
> 1 阶变换；另外 8 张结构表（约 1,200 万行）零因子覆盖。

## 1. 诊断：为什么现在想不出因子

`docs/notes/20261031_factor_report_v2.md` 的全库实测已经给出了答案，只是没被当成
「创新方向」读：

| 观察 | 数字 | 含义 |
|---|---|---|
| 价量因子数 | 86 个声明（liquidity 35 / momentum 20 / risk 25 / reversal 3 / size 3），相关矩阵覆盖其中 81 个 | 只来自 `ohlcv_1d` |
| 高相关对 | 81 个因子里 **71 对 \|ρ\|≥0.9**，聚成 **16 簇** | 有效独立押注 ≈ 16 个 |
| 同族重复 | `turnover_ma_20d` vs `21d` ρ=0.9995 | 换窗口 = 复制粘贴 |
| 评级分布 | 0A / 5B / 18C / 123D | 123 个 D 不是「想法不够」 |
| D 级归因 | 无信号 38 / 传导断裂 68 / 证据不足 12 / 数据不足 2 / 方向错 3 | 68 个有 IC 无价差 |
| 已注册类别 | sentiment、analyst、leverage **各 0 个因子** | 白名单写好了，因子没写 |
| 闲置数据 | moneyflow 503 万行、margin 561 万行、block_trade 31 万、holder 27 万、top_list 12 万、repurchase 5.4 万、share_float 7,841、concept 34 万 | 全部未进因子库 |

三条硬事实：

1. **同一数据 + 同一窗口族 = 重复**。继续在换手率上加 `84d`、`168d`，是在做
   「同一个押注的第 12 个变体」，只会推高相关性，不会提高信息比。
2. **能赚钱的是「变化」而不是「水平」**。库内水平类（换手率均值、成交额、波动率）
   IC 多在 0.01–0.02；冠军 `turnover_std_bias` 是 `std(42)/std(252)−1`，即
   **换手波动的变化率**，IC 0.032、B 级 81.5、净 +0.172%/期。
3. **冠军不是一个公式，是一类生成方式**。它是「把某个水平量做二阶化」的第一个样本；
   同一台机器可以在成交额、波动率、大单净流入、融资余额上重复执行——第 4 节已验证其中三处。

## 2. 五个生成器（可机械执行，不需要灵感）

### G1 升阶：水平 → 变化 → 变化的变化

对任意水平量 `X`（换手率、成交额、波动率、|收益|、融资余额、大单净额）：

| 模板 | 公式 | 经济含义 |
|---|---|---|
| 相对水平 | `MA_s(X) / MA_l(X) − 1` | 短期相对长期的偏离（冠军即此型） |
| 自身分位 | `zscore(X, 252)` | 当前处于自身历史的什么位置 |
| 离散度比 | `std_s(X) / std_l(X) − 1` | 稳定性/波动状态的变化 |
| 加速度 | `[MA5(X)−MA20(X)] − [MA20(X)−MA60(X)]` | 变化率的变化率 |
| 持续性 | `mean(sign(ΔX) 与长期同号的天数占比)` | 趋势的可靠度 |

> 已验证：把该模板套到**成交额**上（`amount_bias_21_252`），信号 IC 0.0426，
> 接近冠军的 0.0449，且与冠军 ρ=0.67——说明「二阶化」确实可机械复制，但同一
> 数据内的二阶化彼此仍然高度相关（见第 4 节）。

### G2 换数据：每张没进因子库的表 → 一族因子

这是当前**唯一能显著降低相关性**的方向。映射表见第 3 节。

### G3 换横截面处理

不加新数据，只改截面处理：行业内 rank/z、市值中性、beta 中性、剔除 ST/次新。
已验证：冠军做行业内 z 后 IC 从 0.0449 降到 0.0337，但净价差从 +0.48% 升到 +0.65%
——**IC 与可交易性不是一回事**，横截面处理常常是「救活」而非「增强」。

### G4 换条件：只在某些状态下有效

把因子拆成「高波动 / 低波动」「大盘 / 小盘」「沪深300 成分 / 非成分」分别看 IC。
若只在某个域有效，正确做法不是丢掉，而是做成**交互因子**或**分域使用**。
报告里已有 `regime` 字段，缺的是按域出 IC 表。

### G5 救活失败因子：68 个「传导断裂」

D 级里 68 个是「有 IC、无价差」——信号在，但分位组合赚不到钱。原因通常是：
极端值、分位内不可交易（涨跌停/停牌）、成本吃掉、或 IC 集中在少数几天。
优先复核这批（成本敏感性、延迟退出、行业内中性化），比新造因子性价比高。

合成（截面百分位等权）：

| 组合 | 信号 IC | t(独立) | 净价差/期 | 相对冠军 |
|---|---|---|---|---|
| 冠军 | +0.0449 | 2.86 | +0.48% | — |
| 冠军 + `margin.balance_chg_20d` | +0.0501 | 3.56 | +0.54% | IC +12% |
| 冠军 + `margin.short_ratio` | +0.0496 | 3.24 | +0.86% | IC +10%，价差 +79% |
| 冠军 + 两者 | **+0.0546** | **3.78** | **+1.00%** | IC +22%，价差 +108% |
| 冠军 + 两者 + `flow.retail_net_ratio_20d` | +0.0583 | 3.89 | +0.88% | IC +30% |

三条读法：

1. **单个新因子都没打赢冠军**，这很正常——库内最好的因子本来就该最难被单个超越。
2. **价值在正交性**：两个两融因子与冠军 ρ 仅 0.14 / 0.16，合成后 IC 和价差同时抬升，
   t 值从 2.86 升到 3.78。这比「再找一个 0.05 的价量因子」现实得多。
3. **二阶化模板可复制，但同一数据内部仍高相关**：`amount_bias` IC 接近冠军（0.043），
   但 ρ=0.67，属于同一个押注的变体。**降低相关性只能靠换数据，不能靠换公式。**

## 5. 优先级路线

### 两周内（低成本、高确定性）

1. 把 `margin.balance_chg_20d`、`margin.short_ratio` 正式注册进
   `Category.SENTIMENT / subcategory="margin"`，走 `F.ts` 与报告全流程复核
   （探针口径 ≠ 报告口径，必须用 `factor_report.py` 复现一次）。
2. 复核与现有 16 簇的最大 ρ：探针只给了「与冠军」的 ρ（0.14 / 0.16），
   要对全部簇复核，需把两融因子的取数分支接进 `scripts/factor_corr.py`
   （目前只支持 `--source price|financial`）。
3. 组合权重用 `composite` + `neutralize=("industry","size")` 复核，避免两融因子被
   小盘/高波动风格吃掉。
4. 给 `top_list` 换构造（净买入占比）再测一次，判断是「信号假」还是「构造差」。

### 一个季度

5. 打通 `Panel` 的辅助数据通道（moneyflow / margin / holder），让这些因子能进
   `factor_report.py` 的标准流程，而不是留在探针脚本里。
6. 按第 3 节队列补齐 sentiment 族 12–15 个因子，每族只保留与现有 16 簇 ρ<0.5 的。
7. 对 68 个「传导断裂」D 因子做一轮成本敏感性 + 行业内中性化的复核，预期能救回 5–10 个。

### 验收线（避免自欺）

- 新因子必须在**同一时间窗**上 IC 胜过冠军，或与冠军 ρ<0.4 且 IC>0.02；
- 合成后 t(独立) 提升 ≥ 0.5，且净价差提升 ≥ 20%；
- 全流程用 `factor_report.py` 的评级，不用探针数字对外说话。

## 6. 边界：这批数字不能说明什么

- 池子是 **2017-11-01 单日成交额前 200 只**，不是 point-in-time 全 A，
  退市股缺失带来向上偏差；
- 探针**没有**可交易掩码（涨跌停/停牌）、没有缩尾、没有行业/市值中性化，
  与 `factor_report` 的评级口径不同，只能做同表内横向比较；
- 两融因子样本 2019-01 起、资金流 2022-10 起，**没有覆盖 2015–2018**，
  杠杆类因子在 2015 杠杆牛/熊中的表现未知；
- 本次只测了 12 个候选，没有做多重检验校正；按 t≈2 的阈值，12 次里出现 1 个
  假阳性是正常期望，所以「IC 0.03 + t 2.5」只能算候选，不是结论。

> 一句话：**别再想「下一个公式」，去想「下一张表」。**
