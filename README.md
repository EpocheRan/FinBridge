该项目基于 **Model Context Protocol (MCP)** 标准开发。它主要用于连接底层金融数据源与上层的 AI Agent 或自动化交易策略，提供标准化的数据查询、技术指标计算以及专业的持仓风控管理功能。

### 1. 主要功能模块

*   **MCP 服务器核心 (`MCPserver.py`)**
    *   作为系统的统一入口，基于 `fastmcp` 框架构建。
    *   通过标准协议暴露了数十个工具函数（Tools），支持数据查询、持仓操作和指标计算，方便 LLM（大语言模型）直接调用。
    *   内置完善的日志记录系统。

*   **数据管理模块 (`utils/`)**
    *   **多源数据聚合**: 集成了 `akshare` 和 `baostock`，提供股票 OHLCV 行情、滚动财务指标、证券基本信息等数据。
    *   **数据持久化**: 通过 `DataConnect` 和 `DataLoader` 管理数据库连接（支持 QuestDB/PostgreSQL），实现数据的高效存取。
    *   **交易日历**: 处理复杂的 A 股交易日逻辑。

*   **持仓与风控模块 (`position/`)**
    *   **科学资金管理**: 提供基于 ATR（平均真实波幅）的波动率仓位管理算法。
    *   **全生命周期管理**: 支持从“初始建仓计算” -> “自动止损位设定” -> “加仓信号检测 (金字塔加仓)” -> “平仓记录”的完整流程。
    *   **风险监控**: 具备“僵尸仓位”检测功能，防止无效资金占用。

*   **指标计算引擎 (`indicator/`)**
    *   基于 `backtrader` 封装的轻量级计算引擎。
    *   提供动态的指标计算服务。

### 2. 核心第三方依赖

| 依赖库 | 用途 |
| :--- | :--- |
| **fastmcp** | 实现 Model Context Protocol 协议，构建 Agent 服务端 |
| **akshare** / **baostock** | 获取 A 股市场的实时与历史金融数据 |
| **backtrader** | 专业的量化回测框架，用于技术指标的核心计算 |
| **pandas** | 高性能的数据清洗与处理 |
| **sqlalchemy** / **psycopg2** | 数据库 ORM 与连接驱动 |
